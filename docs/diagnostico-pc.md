# Diagnóstico básico de PC

Guía para ordenar las comprobaciones antes de cambiar algo.

## Pasos

1. Anotar el problema, cuándo empezó y cómo se repite.
2. Revisar alimentación, cables y periféricos.
3. Consultar CPU, memoria, disco, procesos y logs.
4. En red, revisar interfaz, IP, gateway, DNS y puerto del servicio.
5. Anotar el resultado y la siguiente prueba.

Un ping correcto no asegura que una aplicación funcione. DNS puede resolver un nombre aunque el puerto esté cerrado. Un uso alto de disco tampoco demuestra una falla física.

Si hay olor a quemado, batería hinchada o ruido extraño, apagar el equipo y derivar la revisión. No abrir una fuente de alimentación.
